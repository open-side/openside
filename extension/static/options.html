Pair openside

Not paired

In openside on the daemon’s computer, open Settings → Developers → Connect your phone and copy the pairing link. It pairs this browser as your own device for approvals; never give it to an agent. Pairing is cleared when the browser exits.

Use a device token instead

Or from a terminal on the daemon’s computer: openside token create --person --scope read --scope steer --scope approve, then paste its token here. This is your person-device token for approvals; never give it to an agent.

Agent Tabs

Agent Tabs optionally requests debugger metadata permission. Ask does not need it.
