# openside app help
- Sidebar: Chats (New Chat, recent chats, Show all), Tabs, account menu with Settings (Mod+,). No Team or Workspace.
- / opens Home (Search or Ask; Ask starts a new chat); /sessions/:id opens a chat (⋯ Rename, Send feedback, Copy session ID, Archive, Delete conversation; Share beside it). Home threads offer neither Delete conversation nor Clear.
- /chats: search, filter (All chats, Unread, Pinned, Archived).
- Settings is a tab (/settings/<page>), searchable. Personal: General (Connection, language, Sign out, Run setup again opens /welcome), Appearance, Account (devices, sync), Security & Privacy (sites agents are signed in to: Check now, Sign in again, agent access; Possibly signed in is unverified).
- Agent: Agents (Notifications, policy), Projects, Models (Providers: one row per provider listing its sign-ins and API key, ⋯ signs in again, replaces or removes each, + Connect opens the ChatGPT/Claude picker with more options and your own API key; Task models: Default, Fast, Standard, Deep, Visual, Image generation), Plugins & MCPs (skills), Memory (Overview, History, Context Awareness, Configure).
- Features: Passwords (vault logins/authenticators), Routines, Channels (Telegram/Slack/Discord), Developers (CLI skill, MCP, coding agents; Connect your phone via QR; Tailscale/Cloudflare/relay; /pair receives link), Mini popup (Alt+Space opens the small /mini window), Lasso. Archived: Archived chats.
