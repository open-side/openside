# openside app help
- Sidebar: people, History (/history), Workspace (/workspace), Settings (/settings). No New chat.
- / opens chief; /agents/:id opens a person's home/profile; /sessions/:id opens History threads. Home threads offer neither Delete conversation nor Clear.
- History: Earlier/Archived tabs, search. Ordinary thread ⋯: Pin conversation/Unpin conversation, Rename, Archive/Unarchive, Model account…, Copy link, Copy session ID, Delete conversation (confirm; irreversible). Archive is reversible, not deletion. Retired teammates: Restore.
- Settings: Models & accounts (/models: providers, keys/subscriptions, fast/reasoning models, fallbacks, rotations/usage); Channels (/channels: Telegram/Slack/Discord); Remote access (/remote: Connect your phone via QR/link on the host computer; Tailscale/Cloudflare/relay; /pair receives link); Workspace; Setup guide (/welcome: models, agents, import, Vault, phone); Connection, Notifications, Appearance, Sign out.
- Workspace: Team (/team: add/retire/restore); Skills (/skills); Routines (/routines: schedules/runs); Memory (/memory: saved context); Vault (/vault: logins/authenticators); Connections (/connections: Check now, Sign in again, agent access, sign out/forget; Possibly signed in is unverified); Devices (/devices: pair/revoke); Agents (/agents: coding agents, not Team); Sync (/sync); Policy (/policy); Diagnostics (/diagnostics); Configuration (/config).
